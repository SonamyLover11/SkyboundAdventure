# Skybound Adventure

**Author:** Genesis Rosario  
**Course:** GAM-303: Design of Virtual Game Environments  
**Date:** October 13, 2025  

## Overview
Skybound Adventure is a third-person action prototype created in Unreal Engine 5. 
The game includes interactive elements such as AI enemies, turrets, pickups, 
and a functional main menu with animations. The project demonstrates 
rapid prototyping, level design, and blueprint scripting skills.

## Features
- Main Menu Animation and Level Transition  
- Turret System with Projectile Firing  
- AI Enemy Patrol and Detection  
- Health and Pickup Systems  
- Player HUD with Health Bar and Score Display  

## Controls
- **WASD** – Move  
- **Spacebar** – Jump  
- **Left Mouse Button** – Fire  
- **Esc** – Pause Menu  

## Known Issues
- Occasional delay in turret rotation synchronization.  
- AI sometimes resets patrol loop after respawn.
